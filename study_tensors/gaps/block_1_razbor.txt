=== 2. По вопросам: что ответил, где расхождение, как правильно ===

Вопрос 1 (0/2).
Ответил: «shap = 2» и «вернет [1, 2, 3]».
Что не так: перепутаны ранг и длина — в записи (2, 3) два числа, значит две оси, а 2 — длина
первой оси; и вместо суммы по оси отдан срез x[0] = [1, 2, 3].
Как правильно: x = [[1, 2, 3], [4, 5, 6]] — это 2 строки по 3 числа, shape (2, 3).
x.sum(axis=0) сворачивает ось 0 — строки — и оставляет по числу на каждый столбец:
[1+4, 2+5, 3+6] = [5, 7, 9], форма (3,). x.sum(axis=1) сворачивает ось 1 — числа внутри
каждой строки: [1+2+3, 4+5+6] = [6, 15], форма (2,). x.sum() без axis складывает всё: 21,
форма () — просто число. Свёрнутая ось не «уменьшается», она исчезает из формы целиком.
Шаг проверки: python -c "import numpy as np; x=np.array([[1,2,3],[4,5,6]]); print(x.shape, x.sum(axis=0), x.sum(axis=1), x.sum())"

Вопрос 2 (0/2).
Ответил: «не знаю».
Что не так: не названо правило внутренней оси — без него вопрос решается угадыванием.
Как правильно: A (2, 3) @ B (3, 4) — внутренние оси 3 и 3 совпали, они «съедаются», остаются
крайние 2 и 4: результат (2, 4). B (3, 4) @ A (2, 3) — внутренние 4 и 2 не совпали, умножения
нет, и это не «ошибка numpy», а невозможная операция. A + c, где c (2,): последняя ось A — 3,
последняя ось c — 2, они сравниваются в последнюю очередь и не совпадают; растягивается только
ось длины 1, поэтому отказ. Чтобы сложение прошло, c должен быть (3,): тогда c растягивается
по строкам и прибавляется к каждой.
Шаг проверки: python -c "import numpy as np; A=np.ones((2,3)); B=np.ones((3,4)); print((A@B).shape); print((A+np.ones(3)).shape)"

Вопрос 3 (0/2).
Ответил: «не знаю» — и это вина урока: flatten в нём был одной фразой, без ручки.
Что не так: нечем было ответить, а не «не смог».
Как правильно: батч из 32 картинок 28 на 28 — это (32, 28, 28): ось 0 — примеры, две
последние — пиксели одного примера. flatten склеивает две последние оси: (32, 28, 28) →
(32, 784), потому что 28 × 28 = 784. Linear(784, 128) — матрица весов (784, 128): внутренние
784 совпадают, на выходе (32, 128). Если подать один вектор (784,), батч-оси нет, и слой
выдаст (128,) — вектор; следующий слой ждёт «примеры на признаки», то есть ось примеров,
а получил вектор без неё: он примет его за 128 примеров по одному числу. Правильно —
подавать (1, 784): на выходе (1, 128), батч-ось на месте.
Шаг проверки: python -c "import torch; l=torch.nn.Linear(784,128); print(l(torch.zeros(32,784)).shape, l(torch.zeros(784)).shape, l(torch.zeros(1,784)).shape)"

=== 3. Теория по клеткам (то, ради чего разбор) ===

Клетка t1 «форма и ранг». Запись shape — это список длин осей, а не «сколько всего чисел».
(2, 3) читается так: две оси, первая длиной 2, вторая длиной 3; элементов 2 × 3 = 6.
(3, 2) — те же шесть элементов, но другие оси: 3 строки по 2. (6,) — одна ось длиной 6:
это вектор, а не матрица 1 × 6. Ось длины 1 — полноценная ось: (1, 6) и (6,) дают одинаковые
числа, но разные формы, и для слоёв это разные вещи. Ранг = число чисел в записи.
Шаг проверки: сравните в питоне x.shape у [[1,2,3],[4,5,6]] и у его flatten.

Клетка t13 «суммы по осям». axis=k означает «сверни ось k, остальные оставь». Свёрнутая ось
исчезает из формы, а её длина пропадает; на её месте появляется одно число на каждую
комбинацию остальных осей. Для (2, 3): axis=0 → (3,), axis=1 → (2,), без axis → ().
Отсюда типичная ошибка: сложить «строки» и удивиться, что получилось три числа, а не два —
потому что axis=0 означает «свернуть строки между собой», а не «посчитать строки».
Шаг проверки: возьмите любую матрицу и напечатайте x.sum(axis=0).shape и x.sum(axis=1).shape,
прежде чем считать значения.

Клетка t14 «flatten и батч». Батч — это всегда ось 0, и она неприкосновенна: flatten склеивает
только «внутренние» оси одного примера. (32, 28, 28) → (32, 784) сохраняет 32; (28, 28) → (784,)
теряет батч, если это была одна картинка без батч-оси. Форма (784,) означает «один пример,
784 признака»; форма (1, 784) — «один пример в батче». Для слоя это разница между «вектор»
и «таблица из одной строки».
Шаг проверки: подайте в Linear тензор (784,) и (1, 784) и сравните формы выхода.
