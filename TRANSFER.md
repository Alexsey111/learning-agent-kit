# Передача пакета: Hermes, Claude Code, любой агент

Пакет не зависит от конкретного агента: `AGENT_BRIEF.md` — контракт, `skills/` — процедура
по темам, `trainer/` — рабочий инструмент, `templates/` — формы. Ниже — три способа
развернуть его и чеклист приёмки.

## Вариант 1. Hermes

1. Скопировать папки `skills/*` в каталог скиллов профиля (по одной папке на скилл, рядом
   с категориями). Имена папок = поля `name` в SKILL.md (`direction-diagnostic`,
   `learning-cycle`, `lessons-and-checks`, `kit-acceptance`, `zero-start`).
2. `AGENT_BRIEF.md`, `INTAKE.md`, `TRANSFER.md` положить в рабочую папку ученика.
3. `trainer/` и `study/` — туда же: `start.cmd` рядом с `study/`.
4. Проверить загрузку: список скиллов должен показать четыре новых; описание каждого —
   первая фраза `description`, по ней скилл находится по триггеру.
5. Первый запуск — `python scripts/selftest.py` из корня набора.

## Вариант 2. Claude Code

1. `AGENT_BRIEF.md` → `CLAUDE.md` в корне рабочей папки ученика (или короткий `CLAUDE.md`,
   который ссылается на брифинг).
2. `skills/*/SKILL.md` → `docs/skills/`. Claude Code не подхватывает их сам: в `CLAUDE.md`
   добавь таблицу триггеров, например:
   `«проверяй ответы» / «готово» → docs/skills/02-learning-cycle/SKILL.md`;
   `«начнём учиться» → docs/skills/01-direction-diagnostic/SKILL.md`.
3. `trainer/` и `study/` — в корень; `python trainer/trainer.py --study study`.
4. `start.cmd` под Windows — не забыть CRLF.

## Вариант 3. Любой другой агент

Ему достаточно `AGENT_BRIEF.md` + `templates/` + `trainer/`. Скиллы можно не копировать:
это тот же текст, разложенный по темам, для агентов с механизмом подгрузки.

## Приёмка у получателя (10 минут)

```
python scripts/selftest.py
```

Зелёный вывод означает: файлы на месте, парсер видит примеры, ключ полный, тренажёр поднялся,
принял черновик и итог, записал файлы, порт освободил, `start.cmd` в CRLF.

Дальше вручную:

1. `python -V` — 3.10+. Импорт тренажёра без ошибок (`python -c "import sys; sys.path.insert(0,'trainer'); import trainer"`).
2. Пробный запуск на примере: `python trainer/trainer.py --study study_example --no-browser`,
   открыть `http://127.0.0.1:8765/` — заголовок «БЛОК 1», шесть полей.
3. Заполнить `INTAKE.md` с учеником и развернуть `study/` по-настоящему.
4. Собрать диагностику (30 вопросов) по `skills/01-direction-diagnostic`, проверить парсером,
   отдать ученику.
5. После первой проверки: ключ лежит отдельно, разбор написан, `session` поднят, копия state
   сохранена, тренажёр закрыт, папка снята в архив/коммит.

## Что менять можно, а что нельзя

**Можно и нужно:** предмет (направление, сцены, вопросы, ключи), число тем и сессий,
язык изложения, набор носителей (урок, прибор), формат итоговой приёмки.

**Нельзя без причины:** правила цикла (ключ до ответов, «не знаю» валидно, +3/+10,
не больше двух разборов за сессию, один блок в день, номер сессии = номер файла).
Они выведены из двадцати с лишним сессий реального ученика; каждая «улучшенная» формулировка
ломает сравнение замеров между сессиями.

## Типовые поломки при переносе

| Симптом | Причина | Лечение |
|---|---|---|
| Окно мигнуло, страницы нет | `start.cmd` сохранён с LF | сохранить с CRLF |
| `study/current.txt не найден` | блок не собран | записать блок, проверить парсером |
| Ответы попали в файл прошлой сессии | `session` подняли после запуска тренажёра | поднимать сессию ДО сборки; закрывать старое окно |
| «Готово» не сохранило, поля пусты | тренажёр погасили при открытой вкладке | поднять на том же порту: поля вернутся из localStorage |
| В HTML ноль полей | разметка строится скриптом | вопросы считать парсером, а не grep |
| Кракозябры в консоли Windows | cp866 | читать/писать файлы с `encoding='utf-8'` |
| Порт занят | висит прошлый тренажёр | найти PID на 8765 и снять его |

## Границы пакета

- Он не обещает трудоустройство и не заменяет программу обучения: он её измеряет и ведёт.
- Он не хранит персональные данные в сети: всё лежит файлами рядом с тренажёром.
- Он не даёт готовых вопросов «на все случаи»: их собирает агент под роль, а качество сцены
  проверяется расчётом.
