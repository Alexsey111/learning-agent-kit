# Приёмка набора и первый запуск у нового ученика

Ты получил пакет: инструкцию, скиллы, шаблоны, тренажёр и пример. Твоя первая задача — убедиться,
что он цел, и развернуть его под нового человека, не переписав правила «по вкусу».

## When to Use

- Пакет распакован на новой машине, ученик ещё не начал.
- Переносишь наработки на другой компьютер или другого агента (Hermes → Claude Code и обратно).
- Что-то сломалось: страница не открывается, ответы не сохраняются, номер сессии не тот.
- Не для: ведения самого цикла (`learning-cycle`) и диагностики (`direction-diagnostic`).

## Приёмка: 10 минут

```
python scripts/selftest.py
```

Скрипт делает всё сам: сверяет файлы, парсит пример блока, поднимает тренажёр на свободном
порту, шлёт черновик и итог, проверяет, что файлы ответов появились и содержат ответы,
сверяет ключ (у каждого вопроса назван уровень 2, уровни 1.5/1/0 встречаются, шкала описана;
саму сумму он не считает — это делает `scripts/speccheck.py`, см. ниже). Зелёный вывод —
пакет цел. Красный — сначала починить пакет, потом разговаривать с учеником.

Проверь руками ещё три вещи:

1. **Питон и кодировка.** `python -V`, затем импорт `trainer.py` — только стандартная
   библиотека. На Windows консоль в cp866: файлы читать и писать с `encoding='utf-8'`,
   иначе кириллица падает в трейсбек.
2. **CRLF у `start.cmd`.** cmd.exe не понимает LF-батник: заголовок уедет в команду, окно
   мигнёт и закроется. Проверка: `file start.cmd` должен показать CRLF.
3. **Пустой проект.** Создай `study/` с `state.json` (session 1) и `current.txt` из шаблона,
   запусти `start.cmd`: страница должна отдать заголовок блока «N» и ровно N полей.

## Развёртывание под нового ученика

1. Заполни `INTAKE.md` (фаза 1 брифинга) → `study/INTAKE_filled.md`.
2. Скопируй `templates/state.json` → `study/state.json`, поставь `track`, `topics_order`,
   `session: 1`.
3. Собери диагностику по `skills/01-direction-diagnostic` → `study/current.txt`,
   а если ученик с нуля — сначала урок и игра по `skills/05-zero-start`, потом уже диагностика,
   `study/keys/block_1_key.txt`, `session: 1`.
4. Дай ученику `templates/cycle_rules.txt` — правила цикла его словами (одна страница).
5. Прогони диагностику, посчитай охват и сумму, разложи по клеткам, собери `topic_plan.md`.
6. Дальше — фаза 4 брифинга (цикл), блоки по 6–8 вопросов.

## Куда что кладётся

- **Hermes:** папки из `skills/` скопировать в каталог скиллов профиля как отдельные скиллы
  (по одной папке на скилл, рядом с категориями). `AGENT_BRIEF.md` положить в рабочую папку
  ученика — это контракт, который читается при старте.
- **Claude Code:** `AGENT_BRIEF.md` → `CLAUDE.md` в корне рабочей папки (или ссылка из него),
  `skills/*/SKILL.md` → `docs/skills/`, тренажёр — `trainer/`, данные — `study/`.
  Claude Code не грузит скиллы автоматически: в `CLAUDE.md` напиши триггеры («проверяй ответы»
  → `docs/skills/02-learning-cycle/SKILL.md`).
- **Любой другой агент:** ему достаточно `AGENT_BRIEF.md` + `templates/` + `trainer/`;
  скиллы — та же процедура, разложенная по темам.

## Частые поломки и что смотреть

| Симптом | Причина | Что делать |
|---|---|---|
| Страница не открылась, окно мигнуло | LF у `start.cmd` | сохранить с CRLF |
| `study/current.txt не найден` | не собран блок | собрать блок и записать в current.txt |
| Ответы ушли в файл прошлой сессии | подняли `session` после запуска тренажёра | поднимать сессию ДО сборки блока; закрывать старое окно |
| «Готово» не сохранило, поля пустые после перезапуска | тренажёр погасили при открытой вкладке | поднять на том же порту — поля подтянутся из localStorage |
| В ответе сервера ноль полей | разметка строится скриптом | считать вопросы парсером, а не grep по HTML |
| Кириллица в трейсбеке | консоль cp866 | читать/писать файлы с `encoding='utf-8'` |
| Порт занят | висит прошлый тренажёр | найти PID на 8765 и снять его, потом запускать |

## Чего не делать

- Не переписывать правила цикла под свой вкус: они выведены из 20+ сессий, и каждая
  «улучшенная» формулировка ломает сравнение замеров между сессиями.
- Не начинать с уроков и приборов: сначала диагностика и первый блок, иначе нечего мерить.
- Не менять номер сессии, не сохранив копию state.
- Не выдавать ученику ключ: он лежит отдельным файлом.
- Не обещать трудоустройство и не превращать цикл в курс: у тебя измерение и возвраты.

## Verification

- `python scripts/selftest.py` — зелёный;
- `python scripts/speccheck.py` — зелёный (у гейта свои контроли: на посаженных дефектах он краснеет);
- `start.cmd` в CRLF, страница отдаёт блок и ровно N полей;
- `study/state.json` с session, `current.txt` соответствует ему;
- `INTAKE_filled.md` заполнен шестью полями, `topic_plan.md` собран из диагностики;
- ученик получил `cycle_rules.txt` и понимает, что «не знаю» — нормальный ответ;
- после первой сессии: ключ, разбор, поднятая сессия, закрытый тренажёр, снимок папки.
